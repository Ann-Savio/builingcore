**MONTHLY PERSONAL EXPENSE TRACKER**
 As 1st year engineering students the things we are all struggling to manage is our expense so here i present to u ' Monthly Personal Expense Tracker' 
it is a menu driven expense management application developed using python. 
It helps us record organize, search and manage our mon expenses while keeping track of our monthly allowance and saving goal.
**HOW TO USE**
1.download the project from GitHub and run the following command 'python projectbuildcore.py.
2.when the program starts we can enter our monthly allowance. The  program calculates our savings goal.
3.select the required operation from the available menu. To add expense enter amount category and description.
4.Select view option to display all the recorded expenses .
5.Use search option to find expenses based on category .
6.Use delete option to  delete to  remove an expense based on description.
7.Select total expense to calculate overall spending.
8.Use monthly budget option to monitor your spending.
9.Follow on screen instructions to perform required operations.
